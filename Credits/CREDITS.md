# Credits and asset provenance

CosmoTweest code, rocket/enemy/dreadnought/asteroid sprites, icon, backgrounds, particles, synthesizer sound effects, and musical sequence were created for this project. Artwork is generated by `src/Art.cs`; audio is synthesized by `src/Audio.cs`. No stock imagery, commercial recordings, downloaded game assets, AI-generated bitmap assets, or third-party game libraries are included.

The game uses Windows-provided Segoe UI fonts, WinForms/GDI+, and winmm audio interfaces. Windows fonts and framework binaries are not redistributed. These system components are governed by their respective Microsoft licenses.

Original project code and original assets are provided under the accompanying MIT license.
